## Project Description

The Banking Information System is a beginner-friendly console application developed in Python.
It allows a user to create a bank account, deposit money, withdraw money, check balance,
and view transaction history.

The project demonstrates core Python concepts learned during the internship, including:
- `input()`
- Lists and dictionaries
- `append()`
- User-defined functions using `def`
- File handling
- Basic validation
- Loops and conditional statements

## Files

- `banking_information_system.py` – main Python source code
- `accounts.json` – persistent account data generated/updated by the program
- `README.md` – project documentation
- `requirements.txt` – external dependency information

## How to Run

1. Install Python 3.
2. Open a terminal in this folder.
3. Run:

```bash
python banking_information_system.py
```

The program creates/updates `accounts.json` automatically.

## Main Features

1. Create Account
2. Deposit Money
3. Withdraw Money
4. Check Balance
5. View Transaction History
6. Exit

## Note

This is an educational internship project. It is not intended for handling real banking
transactions or sensitive financial information.
